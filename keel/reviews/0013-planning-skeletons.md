# Рецензія хвилі 0013-planning-skeletons (§9.9, свіжий контекст)

Дата: 2026-09-02. Рецензент: агент з чистим контекстом (не автор).
Вердикт: **приймати після виправлень** — обовʼязкові R-1 і R-2; по
решті — виправлення або відмова вголос. Розібрано: шість знахідок
дістали виправлення цією ж хвилею, одна (R-5) — відмову вголос.
Слова рецензента: «самоукус вилікуваний чесно — редакції сценаріїв
стояли нерухомо по всіх чотирьох коммітах, виправлення назване
вголос у комміті роботи, і новий дизайн ближчий до букви §1.4/§8.5,
ніж старий; серце самоукусу — імʼя свідчить крізь битий документ —
бачене живцем у пісочниці. Але шлях відмови суду числа каже слово,
якого не перевіряв, і власна гілка §8.2 заступає народження
власної ж хвилі».

Жива механіка рецензента: власний повний clone з розгорнутою
історією (перший пакет чесно сказав «дрейф не звірявся — обрізаний
клон», після unshallow якір доведений); пʼять збірок пʼяти дерев з
ізольованими target-ами; пакет судимою командою, звірений з git
diff дослівно; редакції незалежним кодом у чотирьох точках історії;
19 адверсарних пісочниць, понад 50 бігів (у тім збій запису через
chattr +i і суд числа в справжньому репозиторії); самоукус
113a05→5d861c просуджений окремо — тіла сценаріїв тотожні на всіх
чотирьох коммітах, виправлення назване в комміті роботи, дрейф
§4.6 порожній проти доведеного якоря. Чесні зізнання у трьох
власних промахах (тимчасова гілка у спільних refs — прибрана;
англійський греп над україномовним виводом — переміряно; chmod не
тримає root-а). Прибрав за собою все.

## Знахідки

- **R-1 (середня).** «Натомість», що бреше при мовчазному git: суд
  числа у відмові завжди казав «шукав по всіх гілках», навіть коли
  git не назвав жодної і суджено лише диск — обіцяне контрактом
  слово мовчання друкувалось лише на щасливому шляху.
- **R-2 (середня).** Власна гілка §8.2 заступала народження власної
  хвилі: гілка 0500-my-wave чи plan/0501-planned тримала число — і
  keel plan відмовляв власному ж імени, женучи на чуже число, що
  розривало пару гілка↔хвиля.
- **R-3 (легка).** Переповнення числа падало у «не починається
  числом» — причина неправдива: число є, воно лише не влазить.
- **R-4 (легка).** Збій запису казав «файл не читається», хоч ніхто
  не читав; fs::write без temp+rename міг лишити обрубок.
- **R-5 (легка).** Третя байт-у-байт копія предиката §1.2
  (docs::slug_ok, gate::is_slug, plan::is_slug) — жоден механічний
  дзвінок три копії не вирівнює.
- **R-6 (легка).** Тест народження хвилі не звіряв тіла народженого
  файлу — повна форма лишалась кутом.
- **R-7 (легка).** Дві відповіді decisions пережили свій дизайн:
  time-behaviour казала «один скан» (scan у plan більше не біжить),
  recoverability обіцяла цілість, якої fs::write не давав.

Не знайшов: батарея 63×3 зелена (до долі); ключі 383/383 рівними
множинами; check — 29 документів, 0 знахідок обома гілками і по
коммітах; close — дванадцять «закриті», 0013 «в роботі» з одною
нестачею; status — закритих 12; next — «час рецензії»; редакції
незалежно тотожні (tool-plan@5d861c, і 113a05 на план-комміті);
обидва народження чесно червоні падінням тесту, не збірки;
транзієнт §6.5 на плані — «форма не судиться» бінарником того
дерева; вплив §5.7 порожній по-правді, тримачі поіменно чинні;
адверсарно чисте: повтор не перезаписує байт-у-байт, битий сусід
число тримає і народженню не заважає, діри чесні за застереженням
(максимум+1), 007 ловиться об 0007, кривi слаги — §1.2 поіменно,
без тек — школа docs без жодного нишком створеного каталогу, битий
keel.toml — відмова до першого запису, lang=uk — риштування цілком
україномовне, народжений скелет крізь check/status/next — відмова
§3.3 поіменно, «полагодь документ», суд тиші §10.3 називає решту.

## Чотири питання (стисло; повний хід — у чаті сесії)

1. Змовчали про мовчання git на шляху відмови (R-1), про «не
   читається» над записом (R-4), про два рішення, що пережили свій
   дизайн (R-7); дрібне без R: риштування не згадувало depends_on.
2. Неврахований випадок — власна гілка як «суперник» власної хвилі
   (R-2); решта станів (діри, ширини, битi сусіди, remote, повтори)
   враховані і бігами підтверджені.
3. Обіцяне реалізоване без тихих звужень, окрім R-1: слово про
   мовчання git не кажеться там, де воно найпотрібніше.
4. contract-skeleton-born покриває сценарій повністю;
   plan-skeleton-born — кутом: тіло народженого не звірялось (R-6).

## Доля знахідок (запис автора)

Шість виправлень, одна відмова вголос — третього нема.

- **R-1 і R-2 — виправлено.** Друге народження
  `red: plan-skeleton-born` (бачене червоним): гілка, що зветься
  рівно як народжуваний слаг — робоча чи plan/ — пропускається
  судом числа (власне імʼя не суперник, §8.2); при мовчазному git
  «натомість» каже «суджено самі хвилі диска» — «всіх гілках»
  кажеться лише там, де git відповів.
- **R-3 — виправлено:** число, що є, але не влазить у лічбу, —
  відмова з правдивою причиною поіменно (§9.7).
- **R-4 — виправлено:** народження пише в dot-тимчасовий файл і
  приїздить rename-ом — обрубків нема; відмова каже «файл не
  народився», не «не читається».
- **R-5 — відмова вголос.** Третя копія предиката §1.2 лишається:
  модулі свідомо самодостатні за главами (школа gate, названа
  коментарем), а зведення трьох копій в один дім чіпає docs і gate
  поза files цієї хвилі — це окрема хвиля обвʼязки, і її час
  прийде разом з рештою зведень.
- **R-6 — виправлено** тим самим народженням: тіло народженого
  скелета звірене цілим — Why, секції сценарію і трансформи,
  риштувальний заголовок; риштування шапки дістало підказку
  depends_on (дрібне зауваження рецензента).
- **R-7 — виправлено:** обидві відповіді decisions переписані під
  чинний механізм (читання імен замість скану; dot-тимчасовий файл
  з rename-ом замість голого запису).

Після долі: clippy чисто, fmt чисто, 64 тести ×3 зелені, ключі
388/388; `keel check` — 29 документів, 0 знахідок; `keel close` —
дванадцять злитих хвиль «закриті», 0013 «в роботі» з останньою
нестачею, яку закриває саме цей файл.
