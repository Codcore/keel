## Знахідки

- **R-1 (важка).** Репортер node пише `#` в імені як `\#`, `\` як
  `\\`; `tap()` порівнював сирий рядок з іменем із тега. Тег над
  `test('fixes #12')` — зелений тест, а ворота: «біг не виконав жодного
  тесту». Те саме для `a # b`, `back\slash`; імʼя з пробілом у кінці —
  `trim_end` в одному місці і не в другому.
- **R-2 (сер.).** Однакові імена в різних `describe`: ворота брали
  **перший збіг**, батарея — **конʼюнкцію**; `gate` благословляв упалий
  тегований тест під другим `describe`, `close` на тому ж дереві казав
  «червоний тест». Мутація M14 (конʼюнкцію → «останній виграв») вижила
  повну батарею.
- **R-3 (сер.).** Читач тегів знав лише `test(`/`it(`: `test.only(`,
  `test.skip(`, `it.only(`, `await t.test(` (основний API підтестів),
  `await test(`, `const p = test(`, `test  (` — усі «тег не має
  тест-функції». Імʼя з `${}` читалось як `x ${y}`.
- **R-4 (сер.).** «`.ts` читається» — жодна проба: мутація T04 (`ts`/`mts`
  геть із читача) вижила повну батарею.
- **R-5 (легка).** `run_line` для людини ламається на апострофі
  (`bash -c` rc=2); elixir мав ту саму латентну ваду.
- **R-6 (легка).** `NODE_COMPILE_CACHE` у середовищі → `.ncc/` у проєкті
  після `close`; межа не названа, змінна не знята.
- **R-7 (легка).** Контракт: «де здається, що рядок переходить рядок,
  — це апостроф у регулярці, і рядок — код» — не так: решта рядка
  зникала (`const re = /don't/; export function works() {}` → «такої
  одиниці нема»).
- **R-8 (легка).** Обіцянки без проб: M03 (ts перед js), M08 (`^…$`),
  M22 (suite з іменем тесту), H05 (`"…"` — рядок).
- **R-9 (легка).** Журнал «170» — 171; README «сімнадцять» — grep дає
  19; «розійшлась — названо» — для js і python розбіжна сигнатура
  звітувалась як «такої одиниці нема» (`unit_name` знав лише rust-ові
  слова).
- **R-10 (легка).** `keel next` каже `test/` проєкту, що тримає тести
  в `tests/`; форма `/// proves:` у підказці — на всі мови.
- **R-11 (легка).** Згенерований CI для javascript — без проби, node у
  ньому не запінений; `machine_test`, `ignore_reminder_test` — без
  js-випадку.

## Чотири питання — відповіді рецензента

1. **Змовчали** про те, що TAP — теж мова з екрануванням; що межа
   `describe` має дві протилежні реалізації в двох судах; про
   `test.only`/`t.test` — форми з документації node; про середовище.
2. **Сценарії:** ні — імʼя з `#`, підтест, `test.skip` як метод,
   однакові імена під воротами — щоденний node-код, і жоден не в пробах.
3. **Тихе звуження:** не тихе, а несвідоме: «читається з TAP-рядка з
   цим іменем» і «`.ts` читається» виконані наполовину.
4. **Кут:** червоний тегований тест під воротами тримав лише рядковий
   unit; M19, M20, M24, M09 при бігу лише сценарних проб — зелені.

## Не знайшов (шукав — тримає)

Код виходу не читається: SyntaxError у модулі, у файлі тесту, `throw`
при завантаженні, `ERR_MODULE_NOT_FOUND`, enum у strip-only, `type:
commonjs` + `import` — усе відмова зі словами node у `gate` і в
`close`; `if (false)` → «не бігло» при rc=0; `{skip}`, `{todo}`,
`describe.skip` → не бігло; `throw` поза assert, таймаут → червоне.
`.cjs`, `.mjs`, `.ts` з `import type`, `package.json` без `type` —
зелені; `test/`+`tests/`, підтеки, два `toy.test.js` у різних теках
— розрізнено, зелене закриття зміряно. `escape_regex`: `-`, `,`, `=`,
`'`, unicode, `$`, `^`, 3000 символів — проходять. Суд форми: `export
default function`, `export const … =>`, `export async function`, `export
class`, `<T>`, багаторядкова сигнатура, декоратори — зелені; чотири
«привиди» — червоні; 14 шляхів `module_paths`. Одрук `javascrpt` —
відмова з усіма 12 іменами.

## Диспетчеризація автора

**Усі одинадцять зроблено.**

**R-1 — TAP читається як мова.** `unescape_tap` знімає `\#` і `\\`;
директива — перше неекрановане ` # `; пробіл у кінці — частина імені
в обох місцях. Проба `jsnames`: три теговані тести `fixes #12`,
`back\slash`, `trail ` — ворота зелені; unit — те саме без проєкту.
Межа (символи керування) названа в контракті і в черзі.

**R-2 — один суд для однакових імен.** `classify` бере **всі** рядки з
іменем: є `not ok` — червоне; інакше є `ok` — зелене; лише `# SKIP` —
не бігло. Проба `jssame` (упалий тегований під другим `describe` →
ворота червоні), у батареї `jsbattery` — `same` двічі, упалий
**перший** (M14), і unit в обох порядках.

**R-3 — форми node:test.** `js_call` читає `test.only/skip/todo(`,
`it.`-двійники, `await test(`, звʼязану змінну, будь-яку ширину пробілу;
`.skip`/`.todo` — оголошення, вирок «не бігло». Дві речі тег не
тримає, і відмова називає котру: підтест `t.test` (зміряно: під
`--test-name-pattern` з іменем підтесту node не жене нічого — тег на
батька) і імʼя з `${…}`. Проби `jsforms` (5 форм крізь ворота),
`jsskipmethod`/`jstodo`, обидві відмови через `scan_text`, 10 форм
unit-ом.

**R-4** — теги в `.ts`, `.mjs`, `.cjs`, `.mts` поруч із `.js` у `jsread`:
«звірено: 5», і ворота женуть усі пʼять. **R-5** — `shell_quoted` для
рядка людини в js та elixir; проба вставляє рядок у `sh -c` над
`it's fine (a.b)` і читає `ok 1`. **R-6** — `env_remove("NODE_COMPILE_CACHE")`;
проба закриває `jsgreen` з кешем, що показує в проєкт, — `.ncc/` нема.
**R-7** — лапка, що не закрилась на рядку, повертається в код і читання
триває за нею (рішення ruby); проба `jsregexline`; контракт переписано,
межа `//` усередині `/…/` названа. **R-8** — проби: `jstsfirst` (M03),
шим `node` з argv `^a\.b \(x\)$` (M08, M09, M10), unit «suite з іменем
тесту» (M22), `"…"`-привид (H05). **R-9** — журнал 171/173; README:
дев'ятнадцять місць руками і grep як спосіб знайти пропущене (двадцять
рядків); `unit_name` знає `function`, `class`, `def`, `defmodule` — і
`def self.works` називає `works`; проба `jsdiverged` читає «не
сходиться». **R-10** — підказка називає `tests/`, де існує лише вона, і
марку тега мовою проєкту (`//`, `#`); проба `jsnexttests`. **R-11** —
`generated.rs`: крок `actions/setup-node@v4` з `node-version-file:
.nvmrc`/`.node-version`, де проєкт їх тримає, інакше — сказано вголос;
проба з трьома формами; `machine_test` — js-проба без node зупиняється
вголос; рядок «нічого не збирає» — у пробі межі. Ще: у пробі зламу
стверджується і місце помилки (M24 на рівні сценарію).

**Розширення scope, названо вголос (§4.6):** до файлів трансформи
`the-javascript-hand` додано `tool/src/next.rs`, `tool/src/generated.rs`,
`tool/tests/generated_ci_test.rs`, `tool/tests/machine_test.rs` —
`generated` є одним із сімнадцяти місць, які хвиля обіцяла обійти, а
`next` — двома новими, і запис у файлі хвилі каже це.

M14, M19, M20, M22, M24, T04, H05 і по одній-двох на кожну знахідку
