## Знахідки

- **R-1 (варто виправити; умова наступного кроку).** install_hook
  писав у `--git-dir`/hooks — у git-worktree це per-worktree тека,
  якої git при commit-і не читає: «встановлено» вголос, суд мертвий
  тихо (біг B10: справжній commit із зеленим тестом пройшов). Латка —
  `rev-parse --git-path hooks`.
- **R-2 (варто виправити).** Слова сценарію: «де історії нема або
  вона обрізана — вирок не виноситься»; код виносив строгий вирок у
  теці без git (біг C2) — тест тримав лише shallow-половину.
- **R-3 (варто виправити, дешево).** `Red: s` — капіталізований
  двійник народження, найімовірніший одрук поля (git-конвенція любить
  велику), минав суд як «поза судом» (біг A13).
- **R-4 (зауваження).** tool-config обіцяв лише read, а gate/check/
  main спираються на Config/MODES/LANGUAGES — школа R-8 рецензії 0004
  не дотягнута; те саме успадковано в tool-docs (Wave/Transform).
- **R-5 (зауваження).** contracts трансформи gate-command не називали
  tool-rev і tool-docs, хоч gate.rs кличе rev:: і docs:: — школа
  непослідовна в межах однієї шапки.
- **R-6 (зауваження).** Тести слабші за слова сценаріїв, поіменно:
  (а) «ще не перевірено більше не називає теги» — без assert-а;
  (б) «пропуск у кожному режимі» гнався лише під strict; (в) «при
  роботі женуться всі теги» — не тестовано; (г) red на нетегований —
  лише в work-гілці; (д) невідомий mode і висячий тег — обіцянки без
  тестів; (е) фікстури лишали побічну знахідку тиші (covers знятого
  не рахуються), що розмивала exit-код-assert-и.
- **R-7 (зауваження).** Інфраструктурні відмови (exit 2) заслоняють
  commit і в soft — поведінка захисна, але «вирок vs відмова машини»
  ніде не було названо вголос.
- **R-8 (зауваження).** Редакція тега поза формою §5.2 (`s@abc`)
  випливала як переодягнена «застарілість» без слова про кривий
  запис.
- **R-9 (зауваження).** §5.6-благословення історією не відрізняє
  відкриту хвилю від закритої (щабель §6.5); редакція тега при
  red:-народженні не судиться (по словах сценарію — але памʼятати).
- **R-10 (зауваження).** Робота, всі implements якої зняті, проходила
  тихим нулем без слова §2.12.

Де не знайшов: підробок у народженнях; розбіжностей у редакціях і
числах звіту; дір у повноті 40/40 (без перетинів); розбіжностей
i18n (ключ-у-ключ); неіснуючих exports — усі сигнатура-в-сигнатуру.

## Чотири питання (стисло)

1) Сценарії тримаються всі сім, головний потік — так, включно з
end-to-end крізь справжній commit; розходження — R-2 (суворіше за
слова) і R-1 (поле, де обіцянка не доїжджає).
2) Першим у полі — R-1 (worktree — буденні, шкода найгіршого сорту:
успіх уголос, суд мертвий тихо); другим — «Red: s» повз суд; третім —
здивування soft при інфраструктурній відмові.
3) Брехні в тестах нема; недотримання — R-6 поіменно.
4) Зливати можна; умова наступного кроку — R-1.
