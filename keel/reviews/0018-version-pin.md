# Рецензія хвилі 0018-version-pin (§9.9, свіжий контекст)

Дата: 2026-09-03. Рецензент: агент з чистим контекстом (не автор).
Вердикт: **приймати після виправлень** — обовʼязкова R-1; решта
низькі, на розсуд автора: виправлення або відмова вголос. Пʼять
знахідок.

Жива механіка рецензента: власний clone (372 комміти; span хвилі
e02d2b5..ba885ea — план → червоне → робота → журнал — увесь в
історії), власний бінарник із власним CARGO_TARGET_DIR, пакет
`keel review` зібраний ним самим (62.6KB) і прочитаний цілим.
Редакції перераховані python-ом незалежно від бінарника: чотири
нові (tool-config@dac6af, tool-version@eaa913, tool-init@18ccc3,
version-pin@a1646e) і дві старі на базі — усі MATCH. Пісочниці: під
чужим піном "9.9.9" (lang="uk") **усі 13 судів** — status, check,
close, next, rev, rev --write, map, review, trust, hook, plan, new
contract, gate через справжній файл повідомлення — відмова exit 2
повністю англійським текстом з обома іменами; init — відмова вголос
+ рама доноситься, keel.toml не торкнуто байтом (рівно
Застереження); лампа `version` — exit 0 у всіх семи станах (held /
mismatch / none / файла нема / битий toml / чужа мова / неіснуючий
корінь). Межові піни `""`, `"0.1.0 "`, `"0.1"`, `"V0.1.0"` — суд
відмовляє всім чотирьом, лампа відповідає. Справжній hook: коміт під
чужим піном заблоковано (exit 1), після вирівнювання — пройшов.
Контрфакти батареї: КФ-1 (read без суду) — червона 72/1; КФ-2
(порівняння довжин) — червона 72/1; **КФ-3 (лише перший символ) —
зелена 73/0** → R-1. §8.3 обома лицями на план-комміті c85fb43:
plan/-гілка — «суд форми не біжить», не-планова назва — рівно дві
знахідки (pin_mismatch, read_unpinned — «одиниці у файлі модуля
нема»). Червоний коміт f591e57 — падіння 0/1 по суті сценарію; diff
червоне→робота — лише rustfmt. Пʼять чесних промахів: exit-коди
крізь pipe (переміряно голим); перший біг hook-а судив авторський
бінарник із PATH (переграно своїм); хибна тривога на суд адаптера
замість піна; awk-рахунок батареї збрехав через розбивку полів;
забутий `git add` у власній пісочниці.

## Знахідки

- **R-1 (обовʼязкова).** Тест тримає сценарій, але не «точну
  рівність» контракту: підробка, що звіряє лише перший символ
  (`pin.chars().next() != running.chars().next()`), пережила
  батарею 73/0 — а близький чужий пін ("0.1.1" проти бігучої
  "0.1.0") під нею судив би проєкт мовчки — рівно те, заради чого
  хвиля існує. Фікс: гілка батареї з близьким чужим піном (школа
  0017 R-5 — кут стає сценарієм); a1646e вціліє.
- **R-2 (низька).** Слова трансформи і рішення
  self-descriptiveness казали «трьома рядками» проти контракту
  tool-version («двома») і факту (біги дають два).
- **R-3 (низька).** Лампа друкувала пін без лапок: пін із
  хвостовим пробілом на око тотожний бігучій версії, порожній пін —
  порожнеча; суд у відмові цитує пін у лапках, лампа — ні.
- **R-4 (низька).** Мовчанка: перенос піна вперед крізь
  strict-hook блокує власний gate (коміт `version = "9.9.9"` зі
  старим бінарником — exit 1); «move the pin — one line in a diff»
  справджується лише з новою версією в руках — ні Застереження, ні
  «натомість» порядку не називали.
- **R-5 (низька).** Пін-суд стоїть над mode без слова: під
  `manual` (суд коміту вимкнено) і `soft` чужий пін блокує однаково
  (exit 2/2). З буквою «не той бінарник ніколи не судить»
  узгоджено, але для оператора manual «машина не суддя» обертається
  найжорсткішим блоком — назвати вголос.

Не знайшов: другого дому порівняння версій (CARGO_PKG_VERSION ×3 —
риштування, лампа, суд; config.version порівнюється лише в
pin_mismatch); витоку сирого читання в суди (read_unpinned кличуть
рівно двоє — лампа і її рядок у main); ослаблення тесту після
червоного; розбіжности редакцій (4/4 + 2/2 MATCH); дірок у
множинах ключів (415/415, version-* 6/6 обома); недекларованих чи
мертвих файлів; суду, який чужий пін обійшов би (13/13); стану, де
лампа відмовила б чи впала (7/7); нечесности §4.6 (ріст files
план→робота — рівно config_test.rs і rev_test.rs, обидві причини
дослівно в тілі 70a52cf); розбіжности журнальних цифр (усі
відтворились).

## Чотири питання (стисло)

1. Змовчали: перенос піна вперед крізь strict-gate (R-4); пін-суд
   вищий за mode (R-5); init під чужим піном говорить раму
   англійською — мову викинуто з відмовою; неіснуючий корінь лампа
   зве «keel.toml нема» — третя правда без свого слова; пін-суд
   біжить двічі на команду (main і модуль) — дешево, не сказано.
2. Три гілки сценарію + риштування — відтворені; поза сценарієм:
   близькі піни (R-1 — головна дірка), пін проти mode (R-5),
   міграція піна (R-4). Дистрибуційна половина — відкладена вголос.
3. Реалізовано все заявлене; звуження названі; тихого нема — окрім
   «трьома рядками» (R-2), де хвиля обіцяла більше, ніж є.
4. Сценарій як написано — тримає (КФ-1, КФ-2 ловляться); точність
   рівности — кут (КФ-3 зелений). Після R-1 — «тримає сценарій».

## Доля знахідок (запис автора)

Всі пʼять — виправлення; відмов нема. Поведінкові (R-1, R-3, R-4)
— другим народженням `red: version-pin`, баченим червоним.

- **R-1 — виправлено:** друга гілка батареї — близький чужий пін
  тієї самої довжини зі спільним першим символом (бігуча версія з
  заміненим останнім символом) мусить відмовити в суді з обома
  іменами і бути «НЕ цей бінарник» для лампи. Доказ бігом: КФ-3
  рецензента поверх нового тесту — **червоний** (падіння на
  R-1-асерті), відновлений код — зелений.
- **R-2 — виправлено:** трансформа і рішення кажуть «двома рядками»
  (пін і вердикт — одним, три правди).
- **R-3 — виправлено:** лампа цитує пін у лапках (held і mismatch,
  обома мовами) — око бачить точні байти; асерт у другому
  народженні.
- **R-4 — виправлено:** «натомість» відмови називає порядок —
  спершу новий бінарник у руках, його gate і пропустить новий пін;
  те саме в Застереженні хвилі; асерт у другому народженні.
- **R-5 — виправлено словом:** контракт tool-config каже, що суд
  піна стоїть над mode — mode керує судом коміту, пін — правом
  бінарника діяти взагалі, тож і manual не пускає чужий бінарник
  (dac6af → 5555a7; шапка хвилі і пін rev_test йдуть слідом з
  рядком історії). Поведінка свідомо лишається: manual вимикає
  суддю коміту, не право чужого бінарника діяти.

Мовчанки з питання 1, не підняті до знахідок (init англійською під
чужим піном; слово для неіснуючого кореня; подвійне читання), —
лишаються в цьому звіті як кандидати; хвиля їх не розширює.

Після долі: clippy чисто, fmt чисто, 74 тести ×3 зелені, ключі
