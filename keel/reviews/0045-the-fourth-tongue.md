## Знахідки

- **R-1 (важка).** Ключ `(стем, імʼя)` склеює `tests/a/test_x.py` і
  `tests/b/test_x.py`: pytest — «3 тести, 1 упав»; суд — «2 тести,
  закрита»; у зворотному порядку збору — «червоний тест». Вирок
  залежить від порядку. Те саме в ruby (`test/a/same_test.rb`).
- **R-2 (важка).** `@pytest.mark.parametrize` → вузли `test_x[1-2]`,
  тег — `test_x`; ворота зелені, закриття — «батарея не виконала
  тесту». Хвиля з параметризованим тестом не закривається ніколи.
- **R-3 (важка).** `skip`/`xfail`/`xpass`: pytest виходить із 0, ворота
  кажуть «проходить», закриття — «падав у кожному бігу». Правда —
  жодне: тест не біг.
- **R-4 (сер.).** Багаторядковий декоратор (форма black) між тегом і
  `def` → «тег не має тест-функції одразу за собою».
- **R-5 (сер.).** `async def test_…` — те саме.
- **R-6 (сер.).** `addopts = "-q"` у `pyproject.toml` гасить `-v`: батарея
  бачить «0 тестів».
- **R-7 (сер.).** `module: .usr.share.x` читає файл **поза проєктом**:
  `Path::join` абсолютного шматка заміняє корінь; заслін 0035 R-2
  ловив лише `/` і `..`.
- **R-8 (сер.).** І `src/toy.py`, і `src/toy/__init__.py`: суд читає
  файл, python вантажить пакет.
- **R-9 (сер.).** Коментар у колонці 0 усередині класу «зачиняє» клас
  для читача.
- **R-10 (сер.).** Вкладений клас: читач дає `TestInner::test`, pytest —
  `TestOuter::TestInner::test`.
- **R-11 (легка).** `first_error` без `E`-рядка віддає банер із
  підкресленнями замість `import file mismatch:`.
- **R-12 (легка).** Код 4 має **третє** значення — помилка вжитку
  (`pytest: error: unrecognized arguments`), а суд каже «не бігло».
- **R-13 (легка).** «Чотирнадцять місць» — у сирці 17: `battery_dir` і
  два в `generated.rs` поза списком.
- **R-14 (легка).** Обіцянки без проб: `*_test.py` (M3), відмова
  батареї на код 2 (M13), `SKIPPED ≠ зелене` (M14), **зелене закриття
  зі збігом тегу й батареї — жодна проба** (M28), `'''` (T4), декоратор
  (T6).
- **R-15 (легка).** «Нічого не пише» міряно після `check`+`gate`, не
  після `close`.

## Чотири питання — відповіді рецензента

1. **Змовчали** про неунікальний стем; про те, що вузол
   параметризованого тесту ≠ імʼя; що код 0 pytest не означає «біг»;
   що читач не знає `async def` і другого рядка декоратора; що
   проєктний `addopts` перекриває руку; що крапка на початку виводить
   за корінь. Контракт чесно записав одне значення коду 4 — з трьох.
2. **Сценарії:** ні — плаский `def test_`, один клас, один docstring;
   форми, що визначають pytest як бігун, відсутні всі.
3. **Тихе звуження:** механіка — ні; «тести читаються і біжать» тримало
   лише для непараметризованих, синхронних, без декоратора, з
   унікальним стемом; «SKIPPED не зелене» — лише в `run_all`.
4. **Кут:** єдиний `close` у python-пробах — червоний; зелене закриття
   не стверджувала жодна проба.

## Диспетчеризація автора

**Усі пʼятнадцять зроблено.**

**R-1 — один ключ на всю родину.** `adapter::battery_key`: шлях від
теки тестів донизу без розширення (`a/test_x`), і суд закриття будує
його **тією самою рукою**, що й адаптери — ruby, elixir, python. Для
rust це той самий стем, що був (тека тестів пласка). Ruby виправлено
разом і має власну пробу (`two_files_of_one_name_are_two_files`).

**R-2** — екземпляри `test_x[…]` згортаються в голе імʼя, зелене лише
коли всі пройшли; один вузол без `[…]` вибирає всі. **R-3** —
`SKIPPED`/`XFAIL`/`XPASS` в мапі нема зовсім: не зелене і не червоне;
код 0 зелений **лише коли підсумок каже `passed`** — друга поправка
виміру до плану. **R-6** — перелік із підсумку `-rA`, який переживає
будь-яку тишу (зміряно з `-qq`, який навіть `-vv` не перекрикує).
**R-12** — третє значення коду 4 (помилка вжитку) — відмова зі словами
pytest. **R-11** — банер без підкреслень плюс рядок під ним.
**R-7** — сегмент, що починається чи кінчається крапкою, —
`Comparability::Outside` у суді форми (той самий заслін, що для `/` і
`..`) **і** порожній перелік шляхів у руці python — другий заслін
дублює перший, і мутація, що його знімає, лишається живою **навмисно**:
це оборона в глибину, а не судима поведінка. **R-8** — пакет перед
файлом. **R-4, R-5, R-9, R-10** — читач: рахунок дужок декоратора,
`async def`, коментар не зачиняє клас, стек класів за відступом.
**R-13** — README каже сімнадцять і показує команду, якою рахувати;
рішення розрізу переписано з числом рецензії. **R-14, R-15** — проби:
зелене закриття зі збігом тегу й батареї, `*_test.py` з тегом, `'''`
із задокументованим тегом усередині, декоратор, `import file
mismatch`, помилка вжитку, «нічого не пише» після `close`.

Мутації рецензента зіграно наново після правок: M3, M13, M14, M28, T4,
T6 — **червонять**; плюс по одній на кожну знахідку R-2…R-12 —
червонять усі, крім R-7 (названо вище). Батарея після: **167 зелених**,
`clippy -D warnings` і `fmt --check` чисті, `keel check .` — 0
знахідок, 110 сигнатур.
