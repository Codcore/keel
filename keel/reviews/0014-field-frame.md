## Чотири питання (стисло; повний хід — у чаті сесії)

1. Змовчали: що команда читає lang, поки контракт каже «не
   читається» (R-1); що наявна тека лишається без .gitkeep (R-2).
2. Не враховані: битий config для мовного шляху і тека без
   .gitkeep — обидва тепер сценарні.
3. Обіцяне без звужень, окрім «доносить те, чого бракує» для
   .gitkeep (R-2).
4. Тест обходив власну діру (.gitkeep-кут) — тепер другий
   народженням не обходить.
