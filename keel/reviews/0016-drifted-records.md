# Рецензія хвилі 0016-drifted-records (§9.9, свіжий контекст)

Дата: 2026-09-03. Рецензент: агент з чистим контекстом (не автор).
Вердикт: **приймати після виправлень** — обовʼязкова R-1; по решті —
виправлення або відмова вголос. Розібрано: пʼять виправлень, дві
відмови вголос.

Жива механіка рецензента: власний повний clone (unshallow, 417
коммітів); перший біг keel review відмовив йому самому — гілка
звалась не як хвиля (§8.2 спрацював на рецензентові); двічі збрехав
собі exit-кодом крізь pipe — переміряв; редакції 10 контрактних і 2
сценарних — незалежним кодом, цифра в цифру; §8.3 підтверджено з
обох боків бінарником план-комміту (на plan/ — «суд форми не
біжить», на не-план — «write … такої одиниці нема»); народження
трьома деревами; 16 адверсарних пісочниць — і **обидві форми R-1
народились з бігів, не з читання** (перша гіпотеза була хибна, біг
показав інакше).

## Знахідки

- **R-1 (середня, обовʼязкова).** Хірургія — підрядкова заміна, не
  «повний токен»: (а) 4-знаковий запис зʼїдав початок 6-знакового —
  у памʼяті поставав 8-hex, перечит відмовляв з хибним звинуваченням
  бездоганного файлу; (б) `rev@X` бив усередину `tool-rev@X` — на
  диск лягала чинна редакція ЧУЖОГО контракту, а рядок звіту брехав
  (проти конституції п.1: слово заявлене, не виведене).
- **R-2 (низька).** «записів переписано: N» рахував пари після
  дедупу — проти двох рядків diff-у цифра не сходилась.
- **R-3 (низька).** Відмова посеред проходу зʼїдала звіт про вже
  виконані переписи — свідком лишався тільки git diff.
- **R-4 (низька).** Тест повної половини light-сценарію тримався
  спільним підрядком «time for the PR» — регресія на легкі слова
  для повної пройшла б зеленою.
- **R-5 (низька).** Дім запису мовчить про нового мешканця:
  doc-слова plan::write_new («never over something that exists») і
  перелік писарів tool-plan відстали — rev --write сідає поверх
  наявного саме цим домом.
- **R-6 (низька).** Рядок мапи interoperability («git не
  кличеться») буквою хибний: close::structural для розійшлих
  посилань закритих свідчить історією git.
- **R-7 (низька, успадкована).** «Journal:» з великої не проходить
  власний gate інструмента (капіталізований двійник слага, §8.4) —
  23 такі комміти від 0001.

Не знайшов: пакет самодостатній по рядках; дрейф §4.6 порожній
git-ом; вплив §5.7 — всі тримачі старих редакцій обох контрактів
поіменно (закриті, §5.6), ріст — чисте додавання, жодна стара
сигнатура не змінена; батарея 69×3; ключі 404/404; check 33/0
обома гілками, 43 сигнатури незалежним рахунком; народження
червоні по деревах; rev --write на самому keel — одинадцять
«лишаю» поіменно, git status порожній до і після; 16 пісочниць
чисті поза знахідками (тіла недоторкані — токени в тілі вціліли;
ідемпотентність; збіжний 4-префікс не переписується; відсутній
контракт — до check; битий документ — відмова до запису; withdrawn
ігнорується узгоджено; renamed_from їде; закрита-без-звіту
переписується правильно; CRLF цілий; дедуп без подвійного рядка;
легкі слова всіма трьома станами).

## Чотири питання (стисло)

1. Змовчали про дім запису поверх наявного (R-5), git у
   структурному суді (R-6), звіт, що гине з відмовою (R-3).
2. Колізії токенів не були ні сценарієм, ні чесним застереженням —
   застереження стверджувало протилежне (R-1).
3. Обіцяне реалізоване; звуження два: «повний токен» був
   підрядком, «записи» — парами.
4. stale-refs-rewritten — весь сценарій по клаузах;
   light-pr-words-honest — повну половину кутом (R-4).

## Доля знахідок (запис автора)

Пʼять виправлень, дві відмови вголос — третього нема.

- **R-1 — виправлено.** Друге народження `red: stale-refs-rewritten`
  (бачене червоним) з обома пастками рецензента: заміна лише
  повного токена — перед ним не слаг-знак, за ним не hex-знак;
  префікс-мікс і слаг-суфікс лягають кожен СВОЄЮ чинною редакцією
  одним бігом, файл читається, звіт не бреше.
- **R-2 — виправлено:** рахунок — по записах (замінах), цифра
  сходиться з diff-ом.
- **R-3 — виправлено:** відмова посеред проходу — червоний рядок у
  звіті і зупинка; слова про вже покладене не зʼїдаються.
- **R-4 — виправлено:** повна хвиля в тесті тримається точним
  «the review lies next to the wave», не спільним підрядком.
- **R-5 — відмова вголос:** plan.rs поза files цієї хвилі — слова
  дому запису і перелік писарів tool-plan їдуть хвилею 0017 (там
  plan.rs уже в scope за рішенням оператора про адаптер).
- **R-6 — виправлено:** рядок мапи називає справжній механізм
  (свідчення історії git у close::structural, §5.6).
- **R-7 — виправлено надалі, історія стоїть:** журнальні комміти
  віднині пишуться малим слагом «journal:» — граматика §8.4
  власного gate; 23 великі «Journal:» в історії не переписуються
  (школа 0011 R-3), названі тут.

Після долі: clippy чисто, fmt чисто, 70 тестів ×3 зелені, ключі
404/404; `keel check` — 33 документи, 0 знахідок; `keel close` —
пʼятнадцять хвиль «закриті», 0016 «в роботі» з останньою нестачею,
яку закриває саме цей файл.
