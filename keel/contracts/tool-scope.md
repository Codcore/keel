Scope (глава 4): файли, названі до роботи, звіряються з гілкою — в
обидва боки.

- `branch_wave` питає git про поточну гілку і повертає імʼя хвилі,
  якщо гілка зветься як хвиля (§8.2). Ні git-а, ні збігу — None, і
  хто кличе, каже про це вголос: scope, який не звірявся, не
  прикидається звіреним.
- `findings` порівнює файли, які гілка змінила проти точки
  розгалуження з main, з обʼєднанням files трансформ хвилі (§4.3):
  зачеплений файл поза списком — знахідка «дрейф» (§4.6); оголошений
  і не зачеплений — знахідка (§4.4, судиться по всій гілці за §4.5).
  Рядки `one new in <тека>/` рахуються строго: жодного нового файлу в
  теці — знахідка, два — знахідка, рівно один — тихо (§4.1).
- Власні файли методики — тека `keel/` — поза scope (§4.8) і в
  порівняння не входять.
- git викликається як команда системи; його відмова — відмова вголос
  із «натомість», не тиша. Модуль нічого не пише.
