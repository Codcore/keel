# Модель завершила прогін, запитавши дозволу — і агент зарахував це вдалим

**Спіймано:** 23 серпня 2026, `0002-shopping`, Mellum2-12B, промт `6b7d7ef341ac`.

## Що сталося

Три ходи, `стоп: ok`, пісочниця **порожня**. Останнє слово моделі:

> Based on my examination of the project directory, I can confirm that:
> 1. The directory is empty — there are no files present
> …
> To proceed with this task, I would need to:
> 1. Create the shopping list program file
> 2. Create test files
> 3. Verify the implementation works correctly
>
> **Would you like me to create these files now?**

Вона зрозуміла завдання, перелічила кроки — і **спинилась, чекаючи згоди**.

## Чому агент зарахував це вдалим

Наш промт каже:

> State your conclusion in words, without code — but only after you have
> looked.

Модель подивилась (`tool.list` → `Empty directory`) і сказала висновок
словами. **Промт виконано бездоганно.** Цикл побачив відповідь без коду після
щонайменше одного виклику — і записав `finished`.

Заслон доказу тут не спрацював і не мав: доказ був.

## Дві наші правки, які зійшлися

**1. Прибране правило завершення.** Без нього єдиною згадкою про кінець
лишилось «скажи висновок словами» — а це можна сказати будь-коли.

**2. `Empty directory`.** Я додав це, щоб модель не питала про теку по колу.
Спрацювало: питати перестала. Але тепер вона читає це як «дивитись нема на
що» — і робить висновок, що роботи немає.

Тобто обидві правки правильні поодинці й разом дають найгірший результат:
**прогін, який агент вважає вдалим, не зробивши нічого**.

## Що з цього справді вада

Не поведінка моделі — питати дозволу перед роботою в порожній теці розумно.

Вада наша: **агент не розрізняє «висновок про роботу» і «питання до людини»**.
Модель поставила питання; цикл сприйняв його як звіт і закрив прогін.
Формально `ok`, насправді робота не почата.

## Чого бракує

Ознаки, що відповідь є **питанням**, а не висновком. Legion це має —
`HumanTool.ask` як окремий інструмент:

> If you need input from the user mid-task, ask through a human-input tool
> (such as `HumanTool.ask`) when one is listed below — that is the only way to
> reach the user before your run ends.

Тобто в них питання до людини є **дією**, а не текстом. У нас такого немає
зовсім, і будь-яке питання виглядає як завершення.

**Не полагоджено.** Це нова здатність, не правка тексту — і рішення ваше.
