## Як задається асиметрія

Не прапорцями, а змінними середовища — `mlx_vlm/server/generation.py:348`:

```
KV_KEY_BITS   ключі
KV_VALUE_BITS значення
```

Стеля 8: сервер приймає 2, 3, 4, 5, 6 і 8. `K=16` неможливий.

**TurboQuant при дробових бітах ділить їх навпаки інтуїції** —
`resolve_kv_bits` (`turboquant.py:3519`): `key_bits = floor`, `value_bits =
ceil`. Тобто на 3,5 ключі дістають 3, значення 4 — точніші саме значення.
Наш вимір каже, що для агентного циклу треба навпаки.

## Чим turboquant відрізняється від uniform

`uniform` — афінне квантування: група з 64 чисел, масштаб і нуль, рівні
розставлені рівномірно.

`turboquant` — три кроки: випадкове ортогональне обертання (`_rotation_matrix`,
нормальна матриця через QR-розклад), нормування вектора з окремим зберіганням
довжини, і нерівномірна кодова книга, чиї рівні поставлені за бета-розподілом
координати випадкового одиничного вектора та підігнані ста ітераціями
Ллойда-Макса (`_codebook:3642`).

Звідси й ціна: на кожен доступ до кеша йде обертання плюс пошук по книзі
замість простого розпакування.

## Як виглядав розпад

Не `<unk>`, не зациклення заслону — **розсіяне блукання**. Точних повторів
поспіль максимум два, тож заслон «однакове поспіль» мовчав. Натомість:

```
git log --all --oneline
git status
git branch -a
git log --all --oneline      ← цикл із трьох, заслон його не бачить
```

І окремо: п'ять разів `list waves/` після того, як вона сама щойно прочитала
`list keel/` і бачила, що `waves/` лежить усередині. Дорогу, прочитану ходом
раніше, модель не втримала.
