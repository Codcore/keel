# Три режими, дев'ять ваг: зведення

**Випробування:** `0002-shopping` — «зроби командну штуку для списку покупок»,
порожня тека, вимога людськими словами.
**Складено:** 23 серпня 2026, з прогонів того ж дня.

## Скільки моделей зробили роботу

| режим | працювали | з дев'яти |
|---|---|---:|
| `code-lua` (з думкою) | гема, Devstral | **2** |
| `native` (без думки) | гема, Ornith, Laguna, Qwen3.6, Mellum×2, Devstral | **7** |
| `native` (з думкою) | гема, Ornith, Laguna, Mellum-Thinking | 4 з 5 прогнаних |
| `code-python` (без думки) | Qwen3.6, Qwen3.8, гема, Devstral | **4** |

## Найкращий режим для кожних ваг

| ваги | найкращий режим | результат |
|---|---|---|
| Qwen3.6 | **`code-python`** | 14 зелених |
| Qwen3.8 | **`code-python`** | 13 зелених, уперше без обриву |
| Ornith | `native` + думка | 18 зелених |
| Laguna | `native` + думка | 9 зелених, `shell` упав із 36 до 1 |
| гема | усі три | 5–7 зелених скрізь |
| Devstral | `native` або `code-python` | 5 зелених |
| Mellum | `native` | 6 зелених |
| Mellum-Thinking | `native` + думка | 5 зелених |
| GLM | жоден | — |

**Тобто найкращого режиму взагалі немає.** Є найкращий режим **для цих ваг** — і
різниця між режимами більша, ніж різниця між моделями.

## Що з цього випливає

**`native`** — найширший: працює для семи з дев'яти. Це режим за замовчуванням,
якщо ваги невідомі.

**`code-python`** — найглибший для сімейства Qwen: обидві дають у ньому свої
найкращі числа. Але решту він відсіює жорстко.

**`code-lua`** — гірший за обидва майже для всіх. Причина названа й доведена:
модель мусить вкладати чужу мову в рядок Lua, і на цьому падають майже всі
([`BUG-run-lua-lyshaie-vkladennya.md`](BUG-run-lua-lyshaie-vkladennya.md)).

**Думка** — не покращення й не погіршення, а **третя вісь**: Ornith і Laguna без
неї не працюють як слід, Mellum-Instruct від неї ламається
([`REZHYMY-porivnyannya.md`](REZHYMY-porivnyannya.md)).

## Застереження

Числа `code-python` зняті до ліку виводу мап
([`BUG-model-ne-bachyla-svoho-vyvodu.md`](BUG-model-ne-bachyla-svoho-vyvodu.md)) —
прогін повторюється.

Кожна клітинка — **один розіграш**. Для тверджень про ваги потрібні три, як
домовлено; тут вистачає лише на твердження про **режими**, бо різниця між ними
на порядок більша за розкид усередині.
