# Laguna кличе інструменти об'єктом JSON, а не програмою

**Коли:** 23 серпня 2026, прямі проби до сервера
**Ваги:** `mlx-community/Laguna-XS-2.1-4bit`

## Проба

Та сама розмова з журналу прогону, надіслана серверові двічі: з оголошеними
`tools` і без. Записано сирий SSE.

| | текст | думка | справжніх `tool_calls` |
|---|---:|---:|---:|
| з інструментами | 5173 симв | 212 | **0** |
| без інструментів | 138 симв | 0 | **0** |

## Два висновки

**Перший: сервер не віддає натівних викликів для цих ваг узагалі.** У жодній із
проб поле `tool_calls` не мало значення — всі шматки порожні. Розбирач
інструментів `mlx_vlm` вибирається за позначками в шаблоні розмови, і для
шаблона Laguna жоден не підійшов. Тобто «native tool calling» для Laguna в
нашому стенді — фікція: усе приходить текстом, і читати це має наш парсер.

**Другий: оголошення інструментів різко міняє обсяг роботи.** 138 символів
проти 5173 — у тридцять сім разів. Модель, яка не бачить оголошення, відповідає
одним рядком; та, що бачить, пише файл.

## Чим вона кличе насправді

Без інструментів, повний текст відповіді:

    Now I need to create the test file. Writing tests:
    ```lua
    {"args": [">", "test_shopping_list.py", "touch_mode=true"], "command": "sh"}
    ```

Тобто **мітка `lua`, а всередині JSON** — виклик оболонкового інструмента, якого
в нас немає. З інструментами вона вживає два загородження: `lua` і голе, і в
голому лежить об'єкт `{"name": …, "arguments": {"code": …}}`.

Наша пісочниця дістає цей JSON як програму Lua й падає. Ззовні це виглядає як
модель, що не вміє писати Lua. Насправді вона пише виклик — просто іншою мовою
викликів, ніж ми читаємо.

## Що з цього випливає для стенда

Місце ліку — не в промті. Промт уже каже прямо, як писати блок, і Laguna його
читає (мітку `lua` вона ставить). Ламається зміст блоку, а не форма.

Можливі шляхи, жоден не перевірений:

* впізнавати JSON усередині блоку `lua` й перекладати його в наш виклик — так
  само, як ми вже складаємо назад програму, порізану розбирачем сервера;
* дописати розбирач інструментів для шаблона Laguna на боці `mlx_vlm`;
* лишити як є й записати в підсумок: ці ваги на нашому стенді не працюють, бо
  говорять іншою мовою викликів.
