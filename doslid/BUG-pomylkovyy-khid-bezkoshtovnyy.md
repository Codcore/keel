# Хід із помилкою не коштував нічого — і цикл ставав нескінченним

**Спіймано:** 22 серпня 2026, `0002-shopping`, Ornith-1.5.
**Ціна:** 248 ходів при стелі 40, прогін не спинявся сам.

## Що було

`KeelAgent.Session.Server.after_turn/4`:

```elixir
case Program.find(Message.text(answered)) do
  :none            -> done(state, answered, turns, used)
  {:error, why}    -> back(state, why, turns, used)          # ← стеля не при чому
  {:ok, _} when turns <= 0 -> over(state, {:failed, {:too_many_turns, …}})
  {:ok, code}      -> work(state, code, turns, used)
end
```

Лічильник зменшує **той, хто кличе**: `work/4` передає далі `turns - 1`. Гілка
помилки передавала `turns` незмінним, а перевірка стелі стояла лише в гілці
успіху.

Отже модель, яка **ніколи** не напише правильного блоку, крутиться вічно:
помилка → нагадування → помилка → нагадування, і жоден хід не витрачається.

## Як це вилізло

Ornith кличе інструмент розміткою Qwen:

```xml
<tool_call>
<function=例>
<parameter name="content">return tool.list('.')</parameter>
</function>
</tool_call>
```

Наш parser її впізнає й чесно каже, що робити. Модель не перебудовується — і
цикл біжить далі. 248 відповідей, 19 тисяч токенів контексту, прогін живий.

## Чесно про власну провину

**Вада була до мене.** Відмова «два блоки за хід» так само нічого не коштувала,
і будь-яка модель, що вперто пише два блоки, крутилася б так само.

**Але побачити її стало легко саме через мою правку.** До неї виклики чужою
розміткою давали `:none` — тобто «модель нічого не покликала», — і спрацьовував
інший заслон: два нагадування про доказ і відмова. Щойно ці виклики почали
вертати `{:error, …}`, шлях пішов у гілку, де ліку немає.

Тобто я прибрав неправду в повідомленні й водночас відчинив нескінченний цикл.

## Лік

```elixir
{:error, _why} when turns <= 0 ->
  over(state, {:failed, {:too_many_turns, ceiling(state)}}, used)

{:error, why} ->
  back(state, why, turns - 1, used + 1)
```

Хід із помилкою — теж хід: модель його витратила й дістала відмову.

## Заразом

У тому ж місці знайшовся український рядок, що йде **в модель**:
`"програма не виконалась: …"`. Тепер `"the program did not run: …"`.
